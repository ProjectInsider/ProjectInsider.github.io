About MetroStore

MetroStore

MetroStore is a community-made app store project inspired by the original Microsoft Store experience from the Windows 8 and early Windows 10 era.

Its goal is to bring classic Metro and Windows Store apps back into an interface that feels native to the Windows version you are using.

Planned versions
MetroStore 1.0for Windows 8
MetroStore 2.0for Windows 8.1
MetroStore 2.5for Windows 10 Beta builds
MetroStore 3.0for Windows 10 RTM

Each release is planned to match the design, APIs and behavior of its target Windows generation instead of using one identical client everywhere.

This website is currently in beta, so downloads and features may change while development continues.
