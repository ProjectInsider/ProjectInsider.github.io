About the creator

I build projects around the Windows experiences that inspire me.

I am an independent Windows enthusiast and developer who enjoys experimenting with software, interface design and operating systems. ProjectInsider is where I bring those experiments together.

A lot of my work is inspired by the Windows 8 and early Windows 10 eras: Metro design, Technical Preview builds, flat interfaces, live tiles, classic Microsoft ideas and the feeling of software being actively explored and changed.

I use these projects to learn, test ideas and build things I would genuinely like to use. ProjectInsider is not affiliated with Microsoft.

About MetroStore

MetroStore is designed as a modern community project with the visual identity of the Windows 8 Store. The goal is to make app discovery simple, visual and familiar, with featured content, categories and an experience that feels native to Metro-style Windows devices.

Development is still in progress, so the public download is marked as Coming Soon. More information, screenshots and release details can be added here as the project evolves.
